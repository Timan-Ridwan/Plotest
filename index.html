⬡ PLORA CAPTCHA TEST LAB

Test your CAPTCHA integration.

A small browser-side test page for the Plora Captcha SDK. Run a challenge, confirm the callback, and capture the short-lived verification token for your own backend test.

Public site keys are designed for browser use. Never enter your private secret key here.

2. Complete the challenge

Move the slider until the object fits its matching shadow, then press Verify.

Waiting for a challenge.

3. Token result

No token received yet.

Tokens expire after 120 seconds and can be verified only once. This page does not send tokens or private secrets to any third party.

Important: test server verification separately

  1. Send the token to your own backend over HTTPS.
  2. From your backend only, POST to https://plora-captcha.raiyan-ridon.workers.dev/v1/siteverify.
  3. Send JSON with secret (your private site secret) and response (the token).
  4. Check that the response contains success: true. Try the same token again; the second verification should fail.

Do not put the private secret in this GitHub Pages site, JavaScript, or a public repository. GitHub Pages is static hosting and cannot keep server secrets.
